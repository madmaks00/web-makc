Architecture & Patterns

MAKC is built on an Offline-First strategy, where local storage (SQLite) in the WPF client serves as the Single Source of Truth (SSOT). This minimizes UI latency in poor network conditions. Data sync and business logic are powered by a scalable microservice architecture using ASP.NET Core.

C# .NET 8.0 WPF & MVVM Toolkit Offline-First ASP.NET Core Web API SignalR WebSockets PostgreSQL & EF Core SQLite Thread-Safety (SemaphoreSlim)

Offline-First & DB Isolation
The app works instantly even offline. An isolated SQLite DB ({UserId}_cached.db) is created for each account. Write-Ahead Logging (WAL) mode is enabled to prevent DB locks during background sync.
// Data isolation and write acceleration
string dbName = $"{StaticStorage.UserId}_cached.db";
optionsBuilder.UseSqlite($"Data Source={dbName}");

// Enable WAL (Read doesn't block write)
command.CommandText = "PRAGMA journal_mode=WAL;";
command.CommandText = "PRAGMA synchronous=NORMAL;";
Delta-Sync & Thread Safety
Instead of loading entire chat histories, the client uses Delta-Sync (GetDelta) — downloading only messages with an ID greater than the local MaxId. Background message sending is protected by SemaphoreSlim.
// Prevention of double sync runs
private readonly SemaphoreSlim _syncLock = new SemaphoreSlim(1, 1);

if (!await _syncLock.WaitAsync(0)) return;
try {
  // Background unsent messages processing...
} finally { _syncLock.Release(); }
WebSockets: SignalR Hub
Real-time communication. The server not only broadcasts messages but returns a database-generated ServerId for mapping to the local DB. The Hub tracks Online/Offline status via OnConnectedAsync.
// ASP.NET Core SignalR Hub
public async Task<int> SendMessage(...) {
  _context.Messages.Add(newMessage);
  await _context.SaveChangesAsync(); // ID Generation

  await Clients.User(receiverId).SendAsync(...);
  return newMessage.Id; // Return ID to WPF client
}

Security: JWT & BCrypt
Passwords are never stored in plain text — BCrypt hashing with automatic salting is used. Authorization is built on JWT Bearer. A custom interceptor extracts tokens from Query params for SignalR.
